# Checklist — Developer Portal

- [x] React, TypeScript e Vite
- [x] Layout responsivo e navegação protegida
- [x] Login e logout com cookie HttpOnly
- [x] Dashboard de Applications, chaves, consumo e billing

- [x] Criação e revogação de API Keys
